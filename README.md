# The Vibe Lab — thevibelab.net

GitHub Pages로 배포되는 정적 사이트예요. `main` 브랜치에 올리면 1분쯤 뒤 https://thevibelab.net 에 반영돼요.

```
index.html                     첫 화면 (게임 목록)
music/pongdang-rhythm/         퐁당 리듬놀이 → thevibelab.net/music/pongdang-rhythm/
CNAME                          연결된 도메인 (thevibelab.net)
```

새 게임은 `music/<게임이름>/index.html`로 넣고, 첫 화면 `index.html`에 카드를 하나 추가하면 돼요.

## 퐁당 리듬놀이 저작권

「퐁당퐁당」·「고향의 봄」의 가락은 홍난파(1898–1941) 작곡으로 《조선동요백곡집》 악보를 따랐고, 「작은 별」은 18세기 프랑스 민요 가락이에요. 세 곡의 가락은 저작권 보호기간이 끝난 공유 저작물이에요.

「퐁당퐁당」(윤석중 작사)과 「고향의 봄」(이원수 작사)의 노랫말은 아직 저작권이 남아 있어서 이 저장소에 넣지 않았어요. 게임 안의 "우리 가사 넣기"로 넣은 가사는 그 기기의 브라우저에만 저장돼요.
